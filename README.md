# IT Help Desk Simulation Lab

## Overview
Designed an enterprise-style IT help desk simulation using Jira Service Management and a virtualized Active Directory environment to troubleshoot end-user technical issues, manage support tickets, and document incident resolutions.

## Lab Environment

Virtualization:
- VMware Workstation

Server:
- Windows Server 2022

Client:
- Windows 11 Pro

Directory Services:
- Active Directory Domain Services (AD DS)

Ticketing System:
- Jira Service Management

## Skills Demonstrated

### IT Service Desk & Incident Management
- Created and managed support tickets using **Jira Service Management**
- Assigned, prioritized, and tracked incidents throughout the ticket lifecycle
- Documented troubleshooting steps, internal notes, and customer communications

---

### Ticket 001: Shared Network Drive Permission Issue
- Investigated an employee's inability to create folders on a shared network drive
- Analyzed and configured **NTFS and SMB share permissions**
- Resolved the permission issue and verified successful folder creation
- Documented the troubleshooting process and incident resolution

[View Documentation](Ticket-001-Shared-Drive-Permissions.md)

---

### Ticket 002: Active Directory Password Reset
- Simulated an employee unable to authenticate to a domain-joined workstation
- Investigated the affected user account and domain password policy
- Practiced **Active Directory password reset procedures**
- Documented troubleshooting and authentication verification procedures

[View Documentation](Ticket-002-Password-Reset.md)

---

### Technical Documentation & End-User Support
- Documented technical issues, troubleshooting procedures, and root cause analysis
- Practiced professional end-user communication through Jira Service Management
- Used screenshots to demonstrate technical troubleshooting and incident management
- Followed security best practices when managing user accounts and permissions
